做出自己的 360° 全景，並用 VR 頭盔觀看（第 5 關）

不需要付費的 VR 平台。全景圖用 AI 從你自己的圖生成，導覽就放在你自己的 GitHub Pages 網站上，電腦、手機、Google Cardboard 和 Meta Quest 都能看。

  1. 選房間：依照第 4 關的平面圖，選 2 到 4 個空間（例如客廳、臥室、你最得意的特色空間）。每個空間準備一張你自己的室內渲染圖或草圖當參考。
  2. 生成全景：到 Skybox AI 註冊免費帳號。用 Remix 上傳你的室內圖（或用 Sketch 模式描出房間輪廓），再寫提示詞，例如「寫實室內，清水混凝土牆，整面落地窗面向松林山谷，木地板，傍晚暖光」。內容要跟你的平面圖一致：窗戶在哪、門通往哪裡、用什麼材料。免費方案的次數和解析度有限制，以網站當下的說明為準。
  3. 下載與檢查：下載 JPG，寬度必須是高度的 2 倍（例如 4096×2048，越大越清楚）。檢查三件事：左右兩邊接起來是否連續、天花板和地板有沒有嚴重扭曲、跟你的平面圖和外觀圖是否一致。不一致的地方寫進第 5 關的決策紀錄。
  4. 放上網站：把全景圖上傳到 pano 資料夾，打開 tours.js，每個房間填一行：名稱、圖檔、要連到哪個房間。熱點位置用「yaw（左右角度）」和「pitch（上下角度）」表示：在導覽頁按「顯示角度」，把畫面中心對準門口，讀出來的數字就是要填的值。
  5. 觀看：
    • 電腦：用滑鼠拖曳，滾輪縮放，點熱點換房間。
    • 手機：按「手機陀螺儀」，轉動手機就能看四周（iPhone 會先問你是否允許「動作與方向」，請按允許）。
    • Google Cardboard：手機橫放，按「Cardboard」，再把手機放進紙盒。看著熱點 1.5 秒，就會移動到下一個房間。輕點螢幕可以離開。
    • Meta Quest：在頭盔裡打開瀏覽器（Meta Quest Browser），輸入你的網址，開啟導覽頁後按「進入 VR（Quest）」，用手把的扳機點熱點。

不想自己改 tours.js 的話，也可以把全景圖上傳到 Momento360 或 Kuula 這類免費全景平台，再把連結放進你的網頁。只是這些平台的免費方案限制常常變動，熱點和 VR 模式能不能用，請以平台當下的說明為準。

怎麼發布到 GitHub Pages（第 6 關）

開始線上填寫 →

最簡單的做法：直接在線上填寫頁一關一關填，上傳圖片和全景圖，最後按「下載我的網頁」得到一個 .html 檔交給老師。想要自己的網址，再照下面的步驟上傳到 GitHub Pages（把下載的檔案改名成 index.html）。

  1. 登入 GitHub，按右上角「＋」→「New repository」，名稱用英文（例如 my-house），選 Public，勾選「Add a README file」，按 Create。
  2. 在 repository 頁面按「Add file」→「Upload files」，把 index.html 和 img 資料夾拖進去，按「Commit changes」。
  3. 到「Settings」→「Pages」，Source 選「Deploy from a branch」，Branch 選 main、資料夾選 / (root)，按 Save。
  4. 等一到兩分鐘，網址會出現在同一頁上方，格式是 https://你的帳號.github.io/my-house/。把網址貼到 Padlet 繳交。

網頁至少要有：一句話概念、六個階段的作品與回答、每一關的決策紀錄、AI 生成紀錄、360° 導覽（或導覽圖片）、成果海報。不要放自己的全名、座號或照片。

360° 導覽使用 Pannellum（MIT 授權）。範例中的學生姓名為虛構。

把一條細長的玻璃盒子架在松林山坡上，讓人住在樹梢的高度，地面幾乎不被挖動。

圖號 01

真實基地選擇

選擇地點、觀察環境、分析優勢與限制
學生思考

我為什麼選擇這裡？

範例回答

我平常在城市裡被聲音和訊息塞滿，想要一個能一個人安靜下來的地方。我選了一片面向山谷的松樹坡地（設定在屏東縣山區、海拔約 800 公尺的假想基地）：清晨霧從谷底升起，傍晚陽光斜斜照進林子。

這塊地很陡，不好蓋房子，但也正因為不容易到達，這裡才安靜。我想試試看：能不能在不破壞山坡的前提下住進森林裡？

優勢
視野開闊，正面就是層層山景；松林有光影和香氣；遠離車聲；已有一條上山的步道可以利用。
限制
前低後高的陡坡，大量整地會破壞植被；颱風和梅雨季雨水會沖刷坡面；濕氣重；交通不便。
我的回應
建築用細柱架高，不大量挖土；入口放在坡上方，直接接步道；雨水從架高的地板下方自然流過。

決策紀錄

我考慮過
海邊的小屋、城市大樓的頂樓、山林坡地
最後決定
山林坡地
為什麼
海邊風大鹽分重、頂樓還是聽得到車聲；山林最能讓我「安靜下來」，雖然坡地難蓋，反而讓設計有挑戰。
連到課本
綠色永續：基地的限制（陡坡、雨水）決定了建築要「輕輕放上去」，而不是把山削平。
圖號 02

建築概念草圖

決定住宅造型、用途、風格與特色
學生思考

我希望在這裡過什麼生活？

範例回答

我想像的一天：早上在平台上喝咖啡看霧散開；白天在大玻璃窗前閱讀、畫畫；晚上屋裡的燈從玻璃透出來，像林子裡的一盞燈籠。

所以這棟房子的用途是「一個人住的靜居兼工作室」，造型是一條水平延伸的長盒子，風格是現代極簡，最大的特色是向山谷懸挑出去的觀景平台。

草圖要先手繪、讓老師蓋章，才能開始用 AI。AI 是幫你把草圖「整理清楚」，不是替你想造型。

造型
一條沿等高線水平延伸的長方體量，右端接一個實心的混凝土盒子
用途
一人居住、休息、閱讀、觀景、創作
風格
現代極簡：清水混凝土、玻璃、鋼構，顏色少、線條直
特色
左側懸挑觀景平台；整面落地玻璃讓室內外界線變模糊

決策紀錄

我考慮過
分散的幾間小木屋／兩層高的塔樓／一條水平長盒子
最後決定
一條水平長盒子
為什麼
小木屋要整好幾塊地；塔樓會冒出樹梢、破壞天際線；長盒子沿著等高線躺下，只需要一排細柱落地。
連到課本
綠色永續＋文化脈絡：排灣、魯凱等族的家屋與高架穀倉，會順著坡地、就地取材、把地板抬離濕地面；我借用的是「抬高、少挖地」這個想法。
圖號 03

建築外觀設計

產生模型、多視角圖與寫實建築影像
學生思考

這棟住宅如何適應環境？

範例回答

我讓建築用四個方法適應山坡：第一，細鋼柱把房子架高，雨水和小動物可以從下面通過，也不用大量挖土。第二，長邊順著等高線，所以坡面被切斷的地方最少。

第三，靠山那一側是實心的清水混凝土盒子，擋住後方的風雨並收納入口；面向山谷那一側才是整面玻璃。第四，平屋頂往外多伸出一段，夏天擋掉高角度的陽光，下雨天平台也不會全濕。

主要材料
清水混凝土（實牆）、大面玻璃、細鋼柱、木地板平台
多視角
斜上俯視看配置、側面看懸挑和柱子、入口看樓梯動線、展示圖看整體
寫實影像
清晨、傍晚、陰天三種光線，檢查建築在不同時間的樣子

AI 生成紀錄

工具
圖像生成 AI（以手繪草圖當參考圖）
我的指令（摘要）
白色建築模型，長方形玻璃量體架高在松林山坡上，右側混凝土盒子，懸挑平台，細柱，步道蜿蜒，四個視角
不滿意的地方
第一版把房子蓋在平地上、柱子太粗，看不出懸挑
我怎麼改
加上「陡坡、前低後高、細鋼柱、懸挑 3 公尺」，並要求側面視角

決策紀錄

我考慮過
木構斜屋頂／全玻璃盒子／混凝土＋玻璃的組合
最後決定
混凝土＋玻璃：靠山實、面谷透
為什麼
全玻璃在颱風季太脆弱、也沒有隱私；斜屋頂會讓水平線斷掉。一實一透，剛好對應「背山面谷」。
連到課本
綠色永續：架高、少開挖、出簷遮陽，都是讓建築去配合環境。
圖號 04

內部空間設計

規劃平面格局、房間功能、動線與室內設計
學生思考

住進這棟房子會舒服嗎？

範例回答

從右側坡上方的入口進來，先經過混凝土盒子裡比較暗、比較窄的玄關，然後空間一下子打開：中間是開放的客廳和閱讀區，最左邊推開玻璃門就是觀景平台。整條動線是一直線，由暗到亮、由窄到寬。

我自己檢查時發現一個大問題：第一版平面只有入口、客廳、閱讀區和平台，沒有臥室，也沒有浴室，根本不能住！所以我把臥室和浴室放進右側的混凝土盒子裡，那裡比較隱密、也比較暗，適合睡覺。

1 入口
右側，接上方步道與樓梯
2 客廳區
中間，大面玻璃面向山景
3 閱讀區
書牆、吊燈、工作桌
4 觀景平台
左側懸挑，木地板
修正後加入
臥室與浴室放在混凝土盒子內（文字修正，圖還沒改）

決策紀錄

我考慮過
把臥室放在平台旁邊看山／放在混凝土盒子裡
最後決定
放在混凝土盒子裡
為什麼
整面玻璃的房間晚上會被外面看見、也很難睡；混凝土盒子安靜、遮光，白天的活動留給玻璃那一側。
連到課本
通用與友善：入口要爬一段樓梯，行動不便的人進不來。改進方式是從坡上方的步道做一條緩坡，直接平接到入口。
圖號 05

360° VR 虛擬導覽

生成全景照片，串聯客廳、臥室與特色空間
學生思考

我的空間設計是否前後一致？

範例回答

我把四個地點串成導覽：入口 → 客廳 → 玻璃通道 → 觀景平台。走一遍之後，我發現有幾個地方前後不一致：

① 展示板上的室內圖右邊是廚房吧台和高腳椅，可是其他渲染圖同一個位置是書牆。② 模型照片的平台看不到欄杆，渲染圖卻有玻璃欄杆。③ 平面圖還沒有畫出我後來加的臥室和浴室。我決定以「書牆＋玻璃欄杆」為準，並在成果網頁上註明哪些圖是舊版本。

全螢幕導覽／用 VR 頭盔或 Cardboard 觀看 →

佔位示意範例的「全景」是把一張平面渲染圖包成局部 360° 畫面，用來示範導覽怎麼串接，所以四周是模糊的。學生正式作品請用 AI 生成真正的 2:1 全景圖，做法見首頁的「做出自己的 360° 全景」。

決策紀錄

檢查方法
照導覽路線走一次，每到一個點就對照平面圖和外觀圖
發現的不一致
吧台 vs 書牆、平台欄杆有無、平面缺臥室浴室
決定
以書牆＋玻璃欄杆為準；臥室與浴室補進平面圖；舊圖標註「早期版本」
圖號 06

互動成果網頁

整合所有作品、決策紀錄與 VR 導覽，發布 GitHub Pages
學生思考

我如何向別人說明自己的設計？

範例回答

我用一句話開場：「把一條細長的玻璃盒子架在松林山坡上，讓人住在樹梢的高度，地面幾乎不被挖動。」接著依照基地 → 草圖 → 外觀 → 室內 → 導覽的順序，每一段都先說我的決定，再放圖當證據。

最後放上 A3 海報，讓看的人可以一次看到全部。網頁比海報多了兩樣東西：可以拖曳的 360° 導覽，以及每一關的決策紀錄，看的人能知道我「為什麼」這樣設計，而不只是看到漂亮的圖。

這一頁本身就是第 6 關的範例

你現在看到的整頁，就是「互動成果網頁」該有的樣子：一句話概念、照順序的作品、每一關的決策紀錄、可以操作的導覽，最後是海報。發布方式請看首頁的「怎麼發布到 GitHub Pages」。

決策紀錄

我考慮過
只放海報／用簡報／做成一頁可以往下捲的網頁
最後決定
一頁式網頁，海報放在最後
為什麼
海報資訊太密，別人不知道從哪裡看起；網頁可以照我的思考順序帶著讀，還能放可操作的導覽。

範例回答

我想要一個在城市裡、但回到家就能和自己相處的地方。我選了住宅區裡的一塊轉角地（設定在屏東市的低密度住宅區，假想基地）：兩面臨路，主要開口朝東南。

轉角地的好處是採光和通風很好；麻煩是兩面都被路人看見，車聲也比較多。所以這塊地讓我開始思考：怎樣才能「住在熱鬧裡，又保有安靜」？

優勢
兩面臨路，採光與通風條件好；東南向，早上的陽光溫和；周圍是低矮住宅，沒有高樓擋住。
限制
兩面被看見、隱私不足；轉角車聲；基地面積小，不能往旁邊擴張；下午有西曬。
我的回應
臨街的牆少開窗，只開一道低矮的長條窗；把建築中間挖空做中庭，窗戶改成向內開。

決策紀錄

我考慮過
巷子裡的中間地／轉角地／郊區的大塊空地
最後決定
住宅區的轉角地
為什麼
郊區太遠、中間地太暗。轉角地光線最好，而它的缺點（被看見）正好逼我想出「向內打開」的設計。
連到課本
文化脈絡：台灣街屋和合院都會用牆和院子，把外面的街和裡面的生活分開。

學生思考

我希望在這裡過什麼生活？

範例回答

我希望回家像是從吵鬧走進安靜：在玄關轉一個彎，外面的聲音就被留在身後，然後看見中庭的光和一棵樹。我想在這裡一個人看書、發呆、聽雨，偶爾找朋友來坐。

我把這個過程畫成四個步驟：封閉 → 轉折 → 開展 → 內觀，房子的造型就從一個實心方盒子開始，一步一步挖出來。

草圖要先手繪、讓老師蓋章，才能開始用 AI。

造型
兩層的白色方盒子，二樓往外錯開，中間挖出中庭
用途
一人居住、閱讀、書寫，偶爾招待朋友
風格
現代極簡、白色量體、木格柵與鐵件
特色
中庭和一棵樹；從封閉到開闊的回家路線

決策紀錄

我考慮過
完整的方盒子／L 型建築留側院／方盒子中間挖空做中庭

側院還是會被路人看到；中庭四周被房子包住，是最私密的戶外空間，每個房間也都能分到光。
連到課本
文化脈絡：傳統三合院中間的「埕」是家人曬穀、聊天的地方；我的中庭是一個人的「埕」，用來曬太陽、看樹、想事情。

學生思考

這棟住宅如何適應環境？

範例回答

臨街的兩面幾乎是白牆，只留一道與視線高度錯開的長條窗，車聲和路人的眼光都被擋在外面。二樓的量體往外錯開，剛好替一樓入口遮雨、遮陽。

白色外牆可以反射陽光、減少吸熱；木格柵擋掉部分西曬，又讓風進得來。所有大面玻璃都朝向中庭，而不是朝向馬路。

主要材料
白色塗料外牆、木質格柵、金屬欄杆、清玻璃
多視角
模型兩個角度、東南向與另一側立面圖
寫實影像
街角外觀、從室內看中庭

決策紀錄

我考慮過
臨街大落地窗／臨街全實牆／實牆加一道長條窗
最後決定
實牆加一道長條窗
為什麼
大落地窗沒有隱私；全實牆太封閉、像倉庫。長條窗讓坐著的人看得到街上的樹，但路人看不進來。
連到課本
綠色永續：白牆反射陽光、格柵遮西曬、中庭讓熱空氣往上排出。
圖號 04

內部空間設計

規劃平面格局、房間功能、動線與室內設計
學生思考

住進這棟房子會舒服嗎？

範例回答

一樓：從入口玄關進來先轉一個彎，看到中庭，再進到挑高的客廳；餐廳、廚房和浴室排在旁邊。二樓：臥室、書房和陽台，每個房間都有一扇窗看向中庭。中庭讓光線和風進到房子中央，白天幾乎不用開燈。

我檢查後發現：臥室全部在二樓，如果哪天腳受傷或年紀大了，上下樓會很辛苦。所以我把一樓靠中庭的一間房間設計成「可以變成臥室」的多用途房，並在樓梯兩側都裝扶手。

1F
1 入口玄關、2 客廳（挑高）、3 餐廳、4 廚房、5 衛浴、6 樓梯、10 中庭
2F
7 臥室、8 書房、9 陽台、衛浴
動線
入口 → 轉折 → 看見中庭 → 客廳挑高（封閉 → 開展）

決策紀錄

我考慮過
所有臥室都在二樓／一樓留一間多用途房
最後決定
一樓留一間多用途房，可當書房、客房或將來的臥室
為什麼
只有一個人住的時候它是書房；朋友來可以當客房；行動不方便時不用爬樓梯。
連到課本
通用與友善：同一個空間能隨著人生階段改變用途，也讓不同身體狀況的人都住得下去。
